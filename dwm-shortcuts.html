DWM Keyboard Shortcuts

Key Legend

Alt = Mod key (Mod1Mask)
Shift = Shift key
Ctrl = Control key

Window Management

Focus & Navigation

Alt + j Focus next window
Alt + k Focus previous window
Alt + Tab Toggle to last viewed tag
Alt + Return Zoom (swap master)
Alt + Shift + j Push window down in stack
Alt + Shift + k Push window up in stack

Window Control

Alt + Shift + c Kill focused window
Alt + Shift + Space Toggle floating
Alt + s Toggle sticky (visible on all tags)
Alt + b Toggle status bar
Alt + Shift + q Quit DWM

Master Area

Alt + h Decrease master width
Alt + l Increase master width
Alt + i Increase master windows
Alt + d Decrease master windows

Gaps

Alt + - Decrease gaps
Alt + = Increase gaps
Alt + Shift + = Reset gaps to 0

Layouts

Layout Switching

Alt + t []= Tiled layout
Alt + f ><> Floating layout
Alt + m [M] Monocle layout
Alt + u [D] Deck layout
Alt + o [@] Spiral layout
Alt + w [@] Spiral layout (duplicate)
Alt + e |M| Centered master
Alt + g HHH Grid layout
Alt + Space Toggle between layouts

Tags/Workspaces

Tag Navigation

Alt + 1-6 View tag 1-6
Alt + 0 View all tags
Alt + Ctrl + 1-6 Toggle view tag 1-6
Alt + Shift + 1-6 Move window to tag 1-6
Alt + Shift + 0 Tag window on all tags
Alt + Ctrl + Shift + 1-6 Toggle window tag 1-6

Monitor Control

Alt + , Focus previous monitor
Alt + . Focus next monitor
Alt + Shift + , Move window to prev monitor
Alt + Shift + . Move window to next monitor

Application Launchers

Core Applications

Alt + Shift + Return Open terminal (st)
Alt + p Run dmenu launcher
Alt + a Password menu
Alt + ` Toggle scratchpad

Browsers & Communication

Alt + Shift + b Open browser
Alt + Shift + f Open Firefox
Alt + Shift + i Open Signal
Alt + Shift + r Open Slack
Alt + Shift + s Surfer search
Alt + Shift + u Surfer browser

Notes & Productivity

Alt + n Notes menu
Alt + Shift + v New note
Alt + Shift + t Search notes
Alt + c Commands reference
Alt + Home Bookmarks
Ctrl + Shift + Home Snippets

AI & Utilities

Alt + [ GPT menu
Alt + q Clipboard LLM query
Alt + Shift + p Pulse audio mixer
Alt + Shift + l Lock screen

Media & System Controls

Volume Control

XF86AudioRaiseVolume Volume up (+5)
XF86AudioLowerVolume Volume down (-5)
XF86AudioMute Toggle mute

Brightness Control

XF86MonBrightnessUp Brightness up
XF86MonBrightnessDown Brightness down
F5 Minimum brightness
F6 Maximum brightness

Screenshots

Print Full screenshot
Ctrl + Print Select area screenshot
Shift + Print Full screenshot with editor
Ctrl + Shift + Print Select area with editor
Ctrl + Shift + p Select area screenshot
Ctrl + Shift + o Screenshot & copy filename

Mouse Bindings

Layout Bar

Left Click on Layout Cycle through layouts
Right Click on Layout Set monocle layout

Window Title & Status

Middle Click on Title Zoom window
Middle Click on Status Open terminal

Window Manipulation

Alt + Left Click Move window (drag)
Alt + Middle Click Toggle floating
Alt + Right Click Resize window (drag)

Tag Bar

Left Click on Tag View tag
Right Click on Tag Toggle view tag
Alt + Left Click on Tag Move window to tag
Alt + Right Click on Tag Toggle window on tag
